## Decision: Focus 100% on ClinicFlow

**Why:**
- Frontend already partially built
- Clear pain point (patient no-shows / missed follow-ups)
- Can do in-person sales in Vizag (fast feedback loop)
- WhatsApp-first = fits India + SE Asia + Middle East markets
- No HIPAA required for India / SE Asia targets

**Avoid targeting USA/UK/EU first** — HIPAA (US) and GDPR (EU) compliance takes months and money.

**Best international markets:** Southeast Asia (Philippines, Malaysia, Thailand), Middle East (UAE, Saudi Arabia), Latin America, Africa. All WhatsApp-heavy, less regulated, digitizing healthcare fast.

## MVP Feature Scope (v1 Only)

Build ONLY these. Nothing else.

1. Supabase auth (clinic signup/login)
2. Patient table (name, phone, last visit date, doctor)
3. WhatsApp reminder trigger (1 template: missed appointment)
4. Dashboard (# patients, # reminders sent, # responded)
5. Deploy (Vercel frontend, Supabase backend)
6. Razorpay billing (India) / Stripe (international)

**Do NOT build for v1:** AI features, prescriptions, analytics reports, multi-location, desktop app.

## Tech Decisions

- **WhatsApp API:** Use **WATI.io** or **Interakt** (NOT Meta directly — too slow). Indian providers, set up in 1-2 days, pay-per-message.
- **Auth + DB:** Supabase
- **Frontend:** Next.js 14 + Tailwind + shadcn/ui
- **Backend:** FastAPI or Supabase Edge Functions
- **Payments India:** Razorpay
- **Payments International:** Stripe
- **Deploy:** Vercel (frontend), Render or Supabase (backend)
